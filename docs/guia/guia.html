Como instalar o Meshtastic Desktop

Passo a passo para Windows, Mac e Linux. Versão {{VERSAO}}.

Antes de começar

Você recebeu um link para uma página com vários arquivos. Baixe apenas o arquivo do seu computador:

Seu computadorArquivo para baixar
Windows 10 ou 11o que termina em .msi
Mac com chip Apple (M1, M2, M3, M4)o que termina em .dmg
Linux Ubuntu ou Debiano que termina em .deb
Linux Fedorao que termina em .rpm
Outro Linuxo que termina em .AppImage
O programa é o Meshtastic oficial, sem nenhuma alteração. Como ele não tem assinatura digital paga, o computador mostra um aviso de segurança na primeira vez que você abre. Isso é normal, e este guia mostra como liberar.
Pode instalar em quantos computadores quiser. O programa não tem licença por computador nem ativação.

Windows

Windows 10 e 11
  1. Dê dois cliques no arquivo .msi que você baixou.
  2. Vai aparecer uma tela azul dizendo "O Windows protegeu o computador". Clique em Mais informações.
    {{CAPTURA windows-smartscreen-1.png}}
  3. Clique em Executar assim mesmo.
    {{CAPTURA windows-smartscreen-2.png}}
  4. Siga as telas do instalador até terminar.
  5. Abra o Meshtastic Desktop pelo menu Iniciar.

Linux

Linux
  1. Ubuntu ou Debian: dê dois cliques no arquivo .deb e clique em Instalar.
  2. Fedora: dê dois cliques no arquivo .rpm e clique em Instalar.
  3. Outros: clique com o botão direito no arquivo .AppImage, abra Propriedades, marque Permitir executar como programa e dê dois cliques nele.

Mac

Mac com chip Apple (macOS 12 ou mais novo)
  1. Dê dois cliques no arquivo .dmg e arraste o Meshtastic Desktop para a pasta Aplicativos.
    {{CAPTURA mac-dmg.png}}
  2. Abra o programa pela pasta Aplicativos. O Mac vai avisar que não pode verificar o programa. Clique em OK.
    {{CAPTURA mac-aviso.png}}
  3. Abra Ajustes do Sistema, depois Privacidade e Segurança. Desça até a mensagem sobre o Meshtastic Desktop e clique em Abrir Mesmo Assim.
    {{CAPTURA mac-privacidade.png}}
  4. Digite a senha do Mac, se pedir, e confirme em Abrir.

Se o Mac disser que o programa "está danificado", abra o aplicativo Terminal, cole a linha abaixo e aperte Enter. Depois abra o programa normalmente.

xattr -dr com.apple.quarantine "/Applications/Meshtastic Desktop.app"

Primeira conexão com o rádio

  1. Ligue o rádio no computador pelo cabo USB.
  2. Abra o Meshtastic Desktop.
  3. Na tela de conexão, escolha a porta USB do rádio.
    {{CAPTURA conexao-usb.png}}
  4. Aguarde a lista de nós aparecer.

Aviso de mensagem na tela

Windows

Abra Configurações, Acessibilidade, Efeitos visuais. Em "Ignorar notificações após este período", escolha 5 minutos.

As mensagens também ficam guardadas na Central de Notificações, no canto inferior direito da tela.

Mac

Abra Ajustes do Sistema, Notificações, Meshtastic Desktop, e escolha o estilo Alertas. Assim o aviso fica na tela até você fechar.

Quando aparecer "versão nova"

O programa avisa quando o projeto oficial lança uma versão nova. Quando isso acontecer, é só pedir para a Dupply que enviamos o novo instalador.
